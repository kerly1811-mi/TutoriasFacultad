Documentación de Endpoints

Sistema Web y Móvil para la Gestión y Reserva de Espacios - FISEI

Método Endpoint Descripción Seguridad (Roles)
GET /api/status Verifica el estado del servidor y base de datos. Público
POST /api/auth/registro Registra un nuevo usuario y encripta su contraseña. Público
POST /api/auth/login Valida credenciales y devuelve el token JWT de sesión. Público
GET /api/espacios Consulta la lista completa de aulas y laboratorios. Cualquier usuario autenticado
POST /api/espacios Crea un nuevo espacio en la facultad. ADMINISTRADOR
GET /api/reservas Consulta la disponibilidad y listado de tutorías. Cualquier usuario autenticado
POST /api/reservas Solicita una tutoría y genera el token para el código QR. Cualquier usuario autenticado
POST /api/asistencias/registrar Registra la asistencia enviando el token del código QR. ESTUDIANTE, ADMINISTRADOR
GET /api/asistencias/reserva/:id_rev Muestra el listado de estudiantes que asistieron a la tutoría. Cualquier usuario autenticado
POST /api/documentos Vincula el enlace de un documento a una tutoría específica. DOCENTE, ADMINISTRADOR
GET /api/documentos/reserva/:id_rev Descarga el material compartido de una tutoría. Docentes, Admins y Estudiantes que asistieron
